# Commanding Presence
*Source: Tasha's Cauldron of Everything p. 42*  

When you make a Charisma ([Intimidation](99%20Game%20Mechanics/CLI/rules/skills.md#Intimidation)), a Charisma ([Performance](99%20Game%20Mechanics/CLI/rules/skills.md#Performance)), or a Charisma ([Persuasion](99%20Game%20Mechanics/CLI/rules/skills.md#Persuasion)) check, you can expend one superiority die and add the superiority die to the ability check.
